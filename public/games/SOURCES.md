# Game card images

Initial card artwork downloaded from the games' App Store listings, served locally:

- Call of Duty: Mobile: https://apps.apple.com/mx/app/call-of-duty-mobile/id1287282214
- Free Fire: https://apps.apple.com/id/app/garena-free-fire/id1300146617
- Fortnite: https://apps.apple.com/us/app/fortnite/id6483539426

Roblox currently uses a text placeholder. The initial artwork can be replaced with the final selected images without changing the routes.
